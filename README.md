# 🍟 Frituras a tu Gusto

**Frituras a tu Gusto** es un pequeño juego 2D para Android en el que trabajas atendiendo clientes en un puesto de frituras.

Tu objetivo es preparar correctamente los pedidos, eligiendo la fritura, las salsas y los condimentos que pide cada cliente.

## 🎮 Cómo jugar

1. Espera a que llegue un cliente.
2. Mira qué ingredientes solicita.
3. Selecciona la fritura correspondiente.
4. Agrega las salsas y condimentos pedidos.
5. Sirve el pedido.
6. ¡Intenta conseguir la mayor puntuación y ganancias posibles!

Cada día cuenta con **8 clientes**.

## ✨ Características

- 🍟 Diferentes tipos de frituras.
- 🥫 Varias salsas.
- 🌶️ Diferentes condimentos.
- 👥 Clientes con pedidos aleatorios.
- 💰 Sistema de puntuación y ganancias.
- 📱 Diseñado para jugarse en dispositivos móviles.
- 🎨 Interfaz colorida y sencilla.
- ⚡ Juego ligero y rápido.

## 📱 Android

El juego está disponible como APK para Android.

**Requisitos recomendados:**
- Android 7.0 o superior.
- Aproximadamente 10 MB de almacenamiento.
